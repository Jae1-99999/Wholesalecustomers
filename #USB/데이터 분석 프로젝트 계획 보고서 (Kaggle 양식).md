### 📋3. 무엇을 분석할 것인가 - 수정필요

- **한 문장 요약**: 도매유통별 고객 분류 후, 판매 채널을 예측합니다.
- **핵심 질문**:
  - 도매유통 고객 데이터를 기반으로 페르소나를 도출했을 때, 각 페르소나는 어떤 판매 채널을 선호하며 이를 예측하는 모형을 어떻게 구축할 수 있는가?
  - 도매유통 고객을 페르소나로 세분화하고 이를 기반으로 선호 판매 채널을 예측했을 때, 각 페르소나·채널 조합별로 어떤 마케팅 액션을 제안할 수 있는가?
- **문제 유형**: ☐ 회귀 ■ 분류 ■ 군집 ☐ 시계열
- **목표변수 Y**: 컬럼명 `Channel` / 척도 `명목형`
- **설명변수 X 표** 

`이 데이터 세트는 도매 유통업체의 고객들에 관한 것입니다. 여기에는 다양한 제품 범주에 대한 연간 지출액(화폐 단위 기준)이 포함되어 있습니다.`

| 컬럼명 | 의미 · 단위 | Y와 관련 있다고 보는 이유 |
|---|---|---|
| `Channel` | 유통채널(Horica:0, Retail:1) | Y종속변수 |
| `Fresh` | 신선식품 연간 구매액 | - |
| `Milk` | 유제품 연간 구매액 | - |
| `Grocery` | 식료품 연간 구매액 | - |
| `Frozen `| 냉동식품 연간 구매액 | - |
| `Detergents_Paper` | 세제 및 종이류 연간 구매액 | - |
| `Delicassen `| 즉석/가공식품 연간 구매액 | - |
> 화폐 단위는 monetary init으로 미제공

> Y와 관련잇다고 보는 이유는 페르소나 분석(비지도학습)으로, 연관성을 현재로서는 입증하기 어렵습니다.

> `Region`(지역  - Lisbon:0, Oporto:1, Other:2) 컬럼은 분석주제와 연관없으므로, 분석 대상에서 제거하려고합니다.

> 핵심 질문은 데이터로 답이 나오는 형태로 작성합니다.     
> - "청소년 우울증을 어떻게 해결할까"(×)
> - "수면시간이 짧은 집단에서 우울 점수가 더 높게 나타나는가"(○)
>
> 빠뜨리기 쉬운 것이 **X와 Y 양쪽에 영향을 주는 변수**입니다. 아이스크림 판매량과 익사 사고 수는 같이 올라가지만 둘 다 기온 때문입니다. 그런 변수가 데이터에 있다면 표에 넣으세요.
